# heaplane

Heap numeric lane values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/heaplane/

## Install / run

```bash
git clone https://github.com/theworker02/heaplane.git
cd heaplane
node src/cli.js
node --test
```
